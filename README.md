# sturdy-spork
Crazy 8s – UI/UX Design Ideation

📌 Project Overview

This project explores the Crazy 8s design thinking technique to generate 8 different ideas for a Food Delivery App Home Screen.

The objective is to explore multiple design possibilities, compare layouts, and select the most effective concept based on user experience.

🎨 Design Process

1. Idea Generation

Created 8 different home screen layout concepts using the Crazy 8s technique.

2. Design Exploration

Explored different arrangements of:

- Search bars
- Food categories
- Promotional banners
- Restaurant listings
- Bottom navigation

3. Best Idea Selection

Compared the 8 concepts and selected the strongest design based on usability, accessibility, and navigation clarity.

🛠️ Tools Used

- Figma
- UI/UX Design Thinking
- Wireframing

🎯 Project Objective

- Improve creative thinking.
- Explore multiple design solutions.
- Understand wireframing.
- Develop user-focused design ideas.
- Learn to evaluate and select design concepts.
